# EclipVPN Windows installer

A self-contained Windows `.exe` that installs EclipVPN onto an OpenWrt router
entirely **offline**, over SSH — for end users who can't run `install.sh` on the
router (GitHub is blocked in RU, dropbear has no sftp). Modern WPF UI, EN/RU,
auto-detects the router, bundles the static binaries it pushes.

## Files (committed)

| File | Role |
| --- | --- |
| `eclip-core.ps1` | install engine: SSH (SSH.NET) + base64-over-ssh file delivery + the install flow (mirrors `install-from-mac.sh`) |
| `install-eclipvpn.ps1` | headless CLI wrapper over the engine |
| `install-eclipvpn-gui.ps1` | WPF GUI (dark card, EN/RU toggle, router auto-detect, colored log) |
| `lang.ru.txt` | Russian UI strings (UTF-8, loaded as data — keeps the GUI script ASCII) |
| `launcher.cs` | C# self-extracting stub: carries `bundle.zip` as a resource, extracts to `%TEMP%`, runs the GUI |
| `build-icon.ps1` | draws the eclipse logo → `eclip.ico` (multi-size) via System.Drawing |
| `build-exe.ps1` | stages everything, zips it, compiles `launcher.cs` with the framework `csc.exe` → `EclipVPN-Installer.exe` |

## Files NOT in git (regenerable — see `.gitignore`)

- `payload/bin/<arch>/` — the static binaries the installer ships to the router:
  `xray`, `sing-box` (harvested from a working router — Go binaries, portable),
  `jq` (jqlang static), `curl` (stunnel/static-curl musl), `ca-certificates.crt`.
  Currently only `aarch64` is bundled.
- `lib/Renci.SshNet.dll` — SSH.NET 2020.0.2 (net40). Fetch:
  `Invoke-WebRequest https://www.nuget.org/api/v2/package/SSH.NET/2020.0.2` then
  extract `lib/net40/Renci.SshNet.dll` (set `[Net.ServicePointManager]::SecurityProtocol = 'Tls12'` first).
- `eclip.ico` — generated by `build-icon.ps1`.
- `EclipVPN-Installer.exe`, `bundle.zip`, `*.log` — build output / scratch.

## Build

```powershell
# one-time: place payload/bin/<arch>/* and lib/Renci.SshNet.dll (see above)
powershell -ExecutionPolicy Bypass -File build-exe.ps1   # auto-runs build-icon.ps1 if eclip.ico is missing
```

`build-exe.ps1` stages the **router source straight from the repo working tree**
(`usr/`, `www/`, `etc/`), so a rebuild always ships the current EclipVPN code —
rebuild after any change under `usr/`/`www/`/`etc/`.

## Run / test

```powershell
powershell -STA -ExecutionPolicy Bypass -File install-eclipvpn-gui.ps1   # GUI from source
# headless: install-eclipvpn.ps1 -RouterHost 192.168.1.1 -Password '...'
# set ECLIP_GUI_SMOKE=1 to build the window and auto-close (CI/headless check)
```

## Notes / gotchas

- Keep the `.ps1` files **pure ASCII** — PS 5.1 reads a BOM-less script as the
  ANSI codepage, so a stray non-ASCII byte desyncs the parser. Localized text
  lives in `lang.ru.txt` (read as UTF-8 data), never inline.
- dropbear aborts an SSH exec request bigger than ~10-16 KB, so files go in
  ~7.5 KB base64 chunks (one `printf` per chunk). ~0.4 MB/s → ~3-4 min for the
  ~85 MB payload.
- The C# stub detects bundle directory entries by empty `entry.Name` (not
  `EndsWith("/")`): .NET Framework's `ZipFile` writes `\` separators.
- The GUI declares its own AppUserModelID so the taskbar shows the EclipVPN icon
  instead of the host `powershell.exe` icon.
